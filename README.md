# 🚀 Personal Portfolio — Cloud & Observability Engineering

Bienvenido a mi sitio web portfolio. Este proyecto es una presentación interactiva y técnica enfocada en mi trayectoria en Observabilidad, Infraestructura Cloud y Arquitectura de Telemetría.

🌐 **Sitio Web en vivo:** [https://goretox.github.io/Portfolio/](https://goretox.github.io/Portfolio/)

---

 🛠️ Tecnologías y Arquitectura del Sitio
- **Hosting:** GitHub Pages
- **Diseño:** Estilo Terminal/Ingeniería (Dark Mode, tipografía *JetBrains Mono*)
- **Estructura:** HTML5 estático & CSS3 responsive (sin dependencias ni frameworks pesados)

---

 📌 Contenido Destacado
- **Áreas de Enfoque:** OpenTelemetry (OTLP), Propagación de Contexto W3C y Elasticsearch.
- **Laboratorios:** Enlaces directos a repositorios con instrumentación en Node.js, Python y pipelines OTLP Collector.
